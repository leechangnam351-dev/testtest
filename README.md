# 복지서비스 개정사항 AI 분석 시스템

> Kordoc MCP와 생성형 AI를 활용하여 기존 안내자료와 신규 사업지침을 비교하고, 서비스별 변경사항을 자동 분석하여 수정목록을 생성하는 시스템

---

## 프로젝트 개요

복지서비스 관련 안내자료는 매년 사업 지침 개정에 따라 수정된다.

기존에는 담당자가 전년도 안내자료와 신규 사업지침을 직접 비교하여 변경사항을 확인하고 수정목록을 작성해야 했다. 그러나 문서 분량이 방대하고 사업 수가 많아 많은 시간과 인력이 소요되며, 변경사항 누락 위험도 존재한다.

본 프로젝트는 Kordoc MCP를 이용해 문서를 구조화하고 생성형 AI를 활용하여 서비스별 변경사항을 자동 분석함으로써 개정 업무를 지원하는 시스템이다.

---

# 문제점

기존 개정 업무는 다음과 같은 한계가 있다.

* 전년도 안내자료와 신규 사업지침을 수작업으로 비교
* 방대한 문서 검토에 많은 시간 소요
* 담당자별 해석 차이 발생
* 변경사항 누락 가능성 존재
* 반복적인 수정목록 작성 업무 발생

---

# 해결방안

본 시스템은 수작업 위주의 비효율적인 개정 업무를 전면 자동화하여 담당자의 업무 부담을 최소화합니다.

### AS-IS (기존 방식)
 
[안내자료 & 지침 준비] → [담당자가 일일이 대조] → [수정사항 수기 기록] → [취합 후 엑셀 작성] 

⚠️ 문서 방대함, 누락 위험 높음, 담당자별 해석 편차 발생
 
### TO-BE (본 시스템 도입 후)
 
[파일 업로드] ──> [AI 자동 대조 및 문장 재구성] ──> [대시보드 시각화 검토] ──> [클릭 한번으로 엑셀 다운로드]

✨ 소요 시간 대폭 단축, AI 기반 누락 방지, 일관된 수정목록 생성
 
---

# ⚠️ 개발 및 실행 필수 고려사항 (핵심)

프로젝트 개발 과정에서 검증된 시스템의 한계점과 아키텍처 변경에 따른 필수 고려사항입니다.  
실행 전 반드시 숙지해야 합니다.

---

## 1. 실행 환경별 파싱 한계 및 데모 모드 안내
- **브라우저 단독 실행(HTML/JS) 버전의 한계**  
  - 보안 및 샌드박스 정책으로 인해 브라우저 환경에서는 로컬에 설치된 `kordoc CLI` 프로그램을 직접 실행하여 PDF/HWPX 텍스트를 추출할 수 없음.
- **현재 버전의 동작**  
  - HTML 단독 실행 버전은 파일 업로드 UI와 OpenRouter API 연동 기능만 제공.  
  - 실제 텍스트 추출 단계는 **하드코딩된 데모 텍스트** 기반으로 수행됨.  
  - 완전 자동화를 위해서는 **로컬 Node.js 백엔드 서버(server.js)** 환경으로 구동하거나 **브라우저용 PDF 파서 라이브러리** 도입 필요.

---

## 2. Kordoc 내장 비교 도구 이슈 및 AI 우회 선회
- 초기 설계 시 `Kordoc MCP`의 `compare_documents` 도구 활용 예정.  
- 그러나 내부 Diff 과정에서 **문서 처리 오류** 발생:  
  > "오류: 문서 처리 중 오류가 발생했습니다"
- 해결 방안:  
  - Kordoc은 각 문서의 **마크다운 텍스트 추출**만 담당.  
  - 추출된 텍스트의 **비교·분석은 생성형 AI(OpenRouter)**에게 전담시키는 파이프라인으로 고도화.

---

## 3. 필수 의존성 설치 및 환경 설정
시스템 구동 및 Kordoc MCP 연동을 위해 아래 패키지들이 누락 없이 설치되어야 함.

### 1) 필수 NPM 패키지 설치
- `pdfjs-dist`  
  - Kordoc MCP 환경 초기화 및 PDF 파싱 에러 방지를 위해 필수 요구됨.

    npm install pdfjs-dist 
 
### 2) 환경 변수 설정 (.env)
- API 프록시 및 모델 호출을 위해 OpenRouter를 사용합니다. 프로젝트 루트에 .env 파일을 생성하고 아래 키를 설정합니다.
  
  OPENROUTER_API_KEY=your_openrouter_api_key_here

# 주요 기능

## 1. 문서 업로드

사용자는 다음 문서를 업로드할 수 있다.

* 기존 안내자료 PDF
* 신규 사업지침 PDF
* HWP 문서

---

## 2. Kordoc MCP 기반 문서 구조화

업로드된 문서를 Kordoc MCP로 분석하여 구조화된 JSON 데이터로 변환한다.

### 생성 파일

```text
project/target_parsed.md     기존 안내자료  파싱 결과
project/compare_parsed.md    신규사업지침  파싱 결과
project/parsed_text.json     분석하여 구조화된 JSON 데이터 
```

---

## 3. 생성형 AI 변경사항 분석

생성형 AI가 기존 문서와 신규 문서를 비교하여 서비스별 변경사항을 분석한다.

### 분석 대상

* 지원대상
* 지원내용
* 지원금액
* 신청방법
* 신청자격
* 문의처
* 기타 정책 변경사항

### 생성 파일

```text
project/analysis_result.json
```

---

## 4. 수정목록 자동 생성

분석 결과를 바탕으로 개정 담당자가 즉시 활용 가능한 수정목록을 생성한다.

### 수정목록 구조

| 서비스명    | 변경항목 | 기존내용  | 변경내용  | 변경사유  |
| ------- | ---- | ----- | ----- | ----- |
| 장애인연금   | 지원대상 | 기존 기준 | 변경 기준 | 대상 확대 |
| 장애수당    | 지원금액 | 월 4만원 | 월 6만원 | 지원 강화 |
| 활동지원서비스 | 신청자격 | 기존 조건 | 개정 조건 | 제도 개선 |

### 생성 파일

```text
project/수정목록.xlsx
```

---

## 5. 결과 시각화

분석 결과는 웹 화면에서 확인할 수 있다.

### 제공 정보

* 서비스명
* 변경항목
* 기존내용
* 변경내용
* 변경사유

변경된 내용은 강조 표시되어 쉽게 확인할 수 있다.

---

## 6. 엑셀 다운로드

분석 결과를 Excel 파일로 변환하여 다운로드할 수 있다.

### 산출물

```text
수정목록.xlsx
```

---

## 7. 자동 배포

GitHub Actions를 이용하여 GitHub Pages에 자동 배포한다.

### 배포 프로세스

```text
Git Push

   ↓

GitHub Actions

   ↓

Build

   ↓

GitHub Pages 배포
```
