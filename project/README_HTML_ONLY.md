# HTML 단독 실행 가이드

## 실행 방법
1. `project/index.html` 파일을 더블클릭해서 브라우저로 엽니다.
2. 상단의 `OpenRouter API Key` 입력란에 키를 입력합니다.
3. `API 키 저장` 버튼을 누르면 브라우저 localStorage에 저장됩니다.
4. 수정대상 파일과 비교대상 파일을 선택한 후 `분석 시작`을 누릅니다.
5. 결과 테이블을 확인하고 `엑셀 다운로드`를 눌러 저장합니다.

## API 키 저장 위치
- 서버/파일에 저장되지 않습니다.
- 브라우저의 localStorage 키 `openrouter_api_key`로 저장됩니다.

## 주의
- HTML 단독 실행에서는 로컬 CLI(`kordoc`)를 직접 실행할 수 없습니다.
- 따라서 파일 파싱 정확도는 파일 포맷과 브라우저 읽기 가능 여부에 따라 달라집니다.
